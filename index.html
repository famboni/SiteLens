How to deploy a free proxy on Cloudflare (≈2 minutes, free forever)
  1. Create a free account at Cloudflare Workers.
  2. Go to Workers & Pages → Create Worker, give it any name, click Deploy.
  3. Click Edit code, delete everything, paste the code below, then Save and Deploy.
  4. Copy your new URL (e.g. https://my-proxy.your-name.workers.dev), append /?url= to it, paste it in the box above and hit Save.
