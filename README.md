# SiteLens — SEO & AI-Search Website Auditor

A single-file, client-side web app that audits any website against 30+ criteria
covering classic SEO and modern AI-search (AEO/GEO) readiness, based on 2026
ranking-factor research.

## Features
- **Single audit** — enter a URL, get an overall score (0–100, graded A–E) plus
  per-element ratings in 5 categories: Technical health, On-page SEO, Content
  quality, Trust & E-E-A-T, and AI search readiness. Every issue comes with an
  explanation and a suggested fix. Reports download as Markdown **or PDF**
  (the PDF is generated by a built-in dependency-free engine — no libraries).
- **Site scan** — discovers the site's pages (from the entry page's links and
  its XML sitemap), audits up to 50 pages individually, then shows: a site
  average score, "site-wide priorities" (issues affecting multiple pages,
  ranked), and a page-by-page breakdown (worst first) with full per-page
  detail. Page limit is configurable (5–50). Scans use the same proxy chain;
  with your own proxy, large scans are much faster.
- **Paste-HTML mode** — if the proxies are blocked or busy, paste the page's
  HTML source (View → Page Source) and audit it locally; only the live server
  checks (robots.txt, sitemap) are skipped.
- **Compare sites** — audit 2–3 sites head-to-head and get an overall rating,
  a one-line verdict per site, and a category breakdown (no low-level detail).

## How it works
The app is 100% static HTML/CSS/JS. Because browsers block cross-origin
fetches, pages are fetched through CORS proxies and analysed locally with the
DOMParser API. Nothing is stored or sent anywhere.

Default chain (automatic fallback): AllOrigins → Jina Reader → CodeTabs → CorsEU.

### If public proxies fail (permanent fix — recommended)
Free public proxies have rate limits and outages. Deploy your own in ~2 minutes,
free forever (100k requests/day on the free tier):

1. Sign in at https://dash.cloudflare.com
2. **Workers & Pages → Create Worker** → name it → **Deploy**
3. **Edit code** → replace everything with the contents of `worker.js` → **Save and Deploy**
4. Copy your worker URL, append `/?url=`, paste it into the app under
   **⚙ Proxy settings** on the Single audit tab → **Save**.

Your proxy is then tried first on every audit; the public ones remain as fallbacks.
(The same instructions and the worker code are also built into the app itself.)

Alternatively use the built-in **paste-HTML mode** — audit a page's source with
no network access at all (only the live robots.txt/sitemap checks are skipped).

Known limits: backlinks/domain authority, real Core Web Vitals, and JS-rendered
content can't be measured client-side — the app links to PageSpeed Insights
and recommends Google Search Console for those.

## Host on GitHub Pages
1. Create a new GitHub repository (e.g. `sitelens`).
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**, set Source to *Deploy from a branch*,
   branch `main`, folder `/ (root)`, and save.
4. Your auditor is live at `https://<your-username>.github.io/sitelens/`.

No build step, no dependencies, no backend.
